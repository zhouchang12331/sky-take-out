# 苍穹外卖 系统

## 项目简介

苍穹外卖 是一个功能完善的外卖点餐系统，包含管理后台和用户端，支持菜品管理、套餐管理、订单处理、数据统计、用户登录等功能。适用于餐饮行业的数字化运营需求。

## 技术架构

- 后端：Spring Boot + MyBatis + MySQL + Redis + WebSocket
- 前端：未包含在代码中（可通过 REST API 对接）
- 文件存储：阿里云 OSS
- 支付集成：微信支付
- 其他特性：JWT 鉴权、缓存管理、定时任务、全局异常处理

## 主要功能模块

### 管理后台功能

- **员工管理**：登录、退出、账号状态管理、员工信息维护
- **分类管理**：菜品/套餐分类的增删改查
- **菜品管理**：菜品信息维护、口味设置、起售停售
- **套餐管理**：套餐创建、菜品关联、起售停售
- **订单管理**：订单状态管理（接单、拒单、取消、派送、完成）、订单查询
- **数据统计**：营业额统计、订单统计、用户统计、销量排名
- **店铺管理**：营业状态设置与查询
- **工作台**：今日数据概览、订单/菜品/套餐统计
- **文件上传**：通用文件上传接口

### 用户端功能

- **用户登录**：微信授权登录
- **地址簿管理**：收货地址增删改查、默认地址设置
- **菜品浏览**：按分类查看菜品
- **套餐浏览**：按分类查看套餐、查看套餐包含菜品
- **购物车管理**：添加商品、查看购物车、清空购物车、减少商品数量
- **订单管理**：下单、支付、历史订单查看、订单详情、取消订单、"再来一单"功能、订单催单
- **店铺状态**：查看店铺是否营业

## 核心技术特点

- **JWT 鉴权**：区分管理后台和用户端的 token 验证
- **Redis 缓存**：用于店铺状态、套餐数据的缓存管理
- **WebSocket**：实现管理后台的实时消息推送
- **微信支付**：集成微信支付 API V3 版本
- **全局异常处理**：统一的异常响应格式
- **自动填充**：使用自定义注解实现创建/更新时间、用户自动填充
- **定时任务**：处理超时订单和配送中的订单

## 模块结构

- **sky-common**：公共常量、异常、工具类
- **sky-pojo**：数据传输对象（DTO）、实体类（Entity）、视图对象（VO）
- **sky-server**：核心业务逻辑、控制器、Mapper、服务实现等

## 开发部署要求

- JDK 1.8+
- MySQL 5.7+
- Redis 3.0+
- 阿里云 OSS 账号配置
- 微信支付商户账号配置
- Maven 3.0+ 用于项目构建

## 接口文档

使用 Swagger2 生成 API 文档：
- 管理后台文档地址：`/swagger-ui.html`
- 用户端文档地址：`/swagger-ui.html`

## 安全特性

- 多种自定义异常处理（账号锁定、密码错误、登录失败等）
- 接口访问权限控制（通过 JWT 拦截器）
- 数据库操作安全（SQL 异常统一处理）

## 扩展性设计

- 所有业务逻辑通过接口抽象，便于后续扩展
- 使用缓存注解（@Cacheable, @CacheEvict）提高系统性能
- 模块化设计，各功能组件低耦合

## 注意事项

- 需要配置 application.yml 中的微信支付、阿里云 OSS 等第三方服务参数
- 生产环境建议开启 Redis 缓存
- 文件上传功能需要配置阿里云 OSS 参数
- 微信支付回调接口需要公网访问地址

该项目是一个完整的外卖业务解决方案，适合餐饮企业快速搭建自己的线上点餐系统。
